Sugoroku-GUI-CSharp
C# Windows Forms で構築された「究極のすごろく 2026」

概要
このプロジェクトは、C#とWindows Formsを用いたデスクトップ版すごろくゲームです。
単なるエンターテインメントとしてのゲームではなく、「構造科学（Structural Science）」の視点に基づき、状態管理とイベント駆動型UIの整合性を重視して設計されています。

技術的特徴
アーキテクチャ: partial クラスを活用し、UI定義（デザイナーコード）とゲームロジックを厳密に分離。

データ永続化: System.Text.Json を採用し、中断したゲームをいつでも再開できるセーブ/ロード機能を実装。

ログシステム: RichTextBox のセレクション制御により、プレイヤーごとのカラーログ出力を実現。

ロジック:

軍事システムのセンサーフュージョンに着想を得た、動的なイベント判定処理。

「激突（Collision）」判定による、プレイヤー間の動的な位置干渉ロジック。

開発の背景
私は航空自衛隊（JASDF）のOBであり、補給部隊でロジスティクス工学を専攻していました。その経験から、ソフトウェアを「単なるコードの集まり」ではなく、「一つの完結した兵器システムや経済構造」として捉えています。

本作においても、サイコロによるランダムな入力（不確定要素）に対し、システムがいかに整合性を保ちながら出力を生成するかという「構造の安定性」をテーマに開発しました。

使用技術
Language: C#

Framework: .NET (Windows Forms)

IDE: Visual Studio 2022

Library: System.Text.Json

セットアップ
リポジトリをクローンします。

SugorokuGame.sln を Visual Studio で開きます。

ビルドして実行（F5）してください。
